## Ocean Health Index: Livelihoods and Economies

This file describes the methods used to prepare data for the livelihoods and economies goal. There are five scripts for Livelihoods & Economies:

(1) To download the Censos Economicos (CE) data and clean it. 
~ohi_goc_prep/LE/censos_economicos.qmd

(2) To calculate the current status of LIV: number of jobs
~ohi_goc_prep/LE/LIV/ce_economic_census/ce_number_jobs.qmd

(3) To calculate the current status of LIV: quality of jobs
~ohi_goc_prep/LE/LIV/ce_economic_census/ce_quality_jobs.qmd

(4) To calculate the current status of ECO: revenue
~ohi_goc_prep/LE/ECO/ce_revenue.qmd

(5) To merge LIV, then merge LIV with ECO
~ohi_goc_prep/LE/merge_liv_eco.qmd

*All others were used for data exploration purposes.*

More information about this goal is available [here](http://ohi-science.org/goals/#livelihoods-and-economies).

The folders in this file include the metadata, R scripts, and data for each assessment year (i.e., the year the assessment was conducted).  The most current year represents the best available data and methods.
